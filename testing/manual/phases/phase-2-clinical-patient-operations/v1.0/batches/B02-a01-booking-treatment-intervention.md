## Flow Overview

This batch checks how a Hairline admin oversees paid bookings and live treatments, and steps in when something goes wrong. Every admin change needs a reason, leaves an audit entry, and goes through a named action. An admin never sets a booking or treatment status by hand.

1. **Treatment oversight** (FR-010 › Screens 7–9). The admin sees every clinic's In Progress cases. From the case detail the admin can correct day statuses and notes, change treatment details (plan days, clinicians, graft estimate; never price, dates or provider), archive and restore head scan photos, and end a treatment on the provider's behalf.
2. **Booking intervention** (FR-006 › Screens 5–11). From the Bookings Management Dashboard the admin opens a booking and uses the action that fits its status:
   - Change Appointment.
   - Cancel Booking.
   - Revive Booking (after the payment window expired).
   - Start Provider-Fault Transfer (the clinic withdrew before treatment).
   - Resolve In-Progress Provider Fault (the clinic was suspended during treatment).
3. **Patient support** (FR-016 › Screen 9, Alternative Flows A7 and A8). Requests that patients send through support (cancel or change an appointment) wait in Booking Support Requests. The admin resolves each one with the matching FR-006 action, or declines it with a reason. Patients affected by a provider problem are flagged "Admin Support Required" until an admin resolves them. Opening medical data needs a written justification.

This batch closes the provider requests raised in B01 (the {P2} medical postponement and the {P4} closed case). It also sets up the {P2} travel-date review used in B05.

**PRD gaps that affect this batch:**

- FR-006 shows Start Provider-Fault Transfer only when a provider withdrawal or drop-out exists, but it does not say where that withdrawal is recorded. The team records it as setup item AD-5.
- FR-010 Screen 8 requires a reason for every admin edit but does not name the reason field.
- The admin menu paths to the FR-010 In Progress Listing (Admin), the Bookings Management Dashboard and the admin notification list are not named.

Record the labels and paths you see.
