## Flow Overview

This batch checks the admin settings the Phase 1 pilot depends on before providers handle inquiries and quotes.

1. **Admin access (FR-031).** The Super Admin creates a limited admin role, invites a team member with it, and the invitee sets up an account (FR-031 › Main Flow, A3). The batch then proves that permissions are enforced live: hidden menus, Access Denied on direct links, role changes applied on the next action, suspension blocking access, and the last Super Admin protected (FR-031 › A2, B5, Business Rules 3 and 7, User Story 6, EC1). The Super Admin also edits a shared provider role and confirms the change reaches the provider dashboard (FR-031 › A4).
2. **Authentication throttling (FR-026 › Main Flow).** Max login attempts and lockout duration are validated at their boundaries, versioned with a change reason, and enforced.
3. **Inquiry and quote configuration (FR-026 › A6, A7, Screens 5a, 5c, 5d, 7).** Treatment-area options, minimum inquiry lead time, inquiry cancellation reasons, quote expiry window, slot-hold duration and their reminder lead times are validated and versioned. Non-retroactive quote expiry is checked in B05 (PR02-FR004-08).
4. **Inquiry questionnaire (FR-025).** A questionnaire set must be complete and published before it can become the active Inquiry questionnaire, which drives the medical alerts that providers and admins see in B05 and B06.

B05 and B06 rely on the settings confirmed here: the default Quote Configuration (48 h expiry window), the active Inquiry questionnaire, and the limited admin role created in A09-FR031-01.
