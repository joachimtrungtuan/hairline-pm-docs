## Flow Overview

This batch tests how a Hairline admin brings a new clinic onto the platform and controls its account status. It is the first step of the Phase 1 pilot journey: no provider can receive inquiries or send quotes until it has been onboarded here.

- **Onboarding (FR-015 › Main Flow: Admin Creates and Activates New Provider).** The admin opens Provider Management, clicks "Add New Provider" and completes the six-step creation wizard: basic info, professional details, clinic info, documents, commission and review. The provider is created as Active, but it has no password yet, so it is held out of inquiry distribution. The owner gets an activation email with a one-time link valid for 24 hours, sets a strong password, logs in and sees the "Welcome to Hairline" prompt (FR-032).
- **Activation recovery (FR-015 › Alternative Flow A1).** If the email is lost or expired, the provider can request a new one from the login page, or the admin can resend it from the provider profile. Older links stop working.
- **Profile administration (FR-015 › Screen 3).** The admin edits basic information (every save needs a reason; Seat Limit changes need the admin password), manages languages and documents, and invites staff on the provider's behalf from the Staff List tab (FR-009 Screen 12).
- **Status control (FR-015 › Alternative Flows A5–A6, Screens 4–5).** The admin can suspend a provider, which leaves it able to log in but in read-only mode with a banner. The admin can reactivate it, or permanently deactivate it, which blocks login. Every action is recorded in the Activity Log.
- **Admin permissions (FR-031).** Admins without the onboarding and status permissions must not be able to perform these actions.

Phase 1 tests immediate status changes only. Scheduled changes, the booking and treatment parts of the suspension cascade, commission editing, Featured management, closure requests and "Login as Provider" are out of scope (see plan §1.2).
